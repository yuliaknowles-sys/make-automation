Behind the scenes

The scenario in Make

In Make, an automation is called a scenario and each step is a module. This one has a single entry point and a router that sends each item down the right branch.

One entry pointEvery item arrives the same way, whether it comes from a form, an email or an expense app.
Rules, not guessworkEach branch has a filter. An item only goes down the branch whose rule it matches.
An answer every timeEach branch replies with where the item landed, so nothing is left in limbo.
